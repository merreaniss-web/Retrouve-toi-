# TEMPO GPS — Urban Black & Yellow

## Installation
1. Fais une copie de sauvegarde de ton `index.html` actuel.
2. Remplace `index.html` par ce fichier dans le dépôt GitHub.
3. Valide avec **Commit changes** et recharge GitHub Pages.

## Refonte incluse
- Identité visuelle urbaine noir / jaune.
- Thème d'interface automatique (suit le système), clair ou sombre. Appuie sur `AUTO / CLAIR / SOMBRE` pour changer. Le choix est mémorisé localement.
- Carte claire ou sombre indépendante de l'interface via le bouton `Carte`.
- Couleurs des trajets et des contrôles adaptées au thème.
- Fonctionnalités préexistantes conservées dans le fichier source.

## À savoir
La carte claire/sombre utilise les styles OpenFreeMap existants dans le prototype. La disponibilité des services cartographiques dépend de leurs conditions et limites. Le changement automatique concerne le thème de l'interface; la carte conserve le mode sélectionné manuellement.
